- [Section structure --- reader-objective-first](feedback_section_structure.md) --- Open empirical sections with the question they serve; walk reader through construction as means to that end, not as code transcription.
- [Figures/tables live in results section](feedback_figure_table_ownership.md) --- All floats owned by `results_current.tex`. Other sections only `\ref` existing labels; never inline duplicate `\begin{figure}` or `\begin{table}` blocks.
- [Skip trivial mechanics in data sections](feedback_skip_trivial_mechanics.md) --- Omit standard machinery JF/RFS readers know (HUD crosswalks, Avery linkage, efficiency-ratio formula, CRA loan cutoffs). Body section is for conceptual content; replication detail goes to appendix.
- [Data section is not the descriptive-stats section](feedback_data_vs_descstats.md) --- Data section describes sample + variable definitions only. Means, SDs, frequencies, summary-stats table references belong in a separate descriptive-stats section.
- [Don't dwell on replications](feedback_replication_vs_contribution.md) --- A replicated finding from cited prior work gets one paragraph as puzzle/setup, never a headline subsection. Subsections are for the paper's contribution only.
